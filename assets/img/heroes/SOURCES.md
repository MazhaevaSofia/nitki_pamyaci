# Фото героинь: источники и лицензии

Все файлы пересохранены в WebP (до 900 px по длинной стороне, качество 85, кадр 3:4).
Маленькие исходники (меньше 600 px) аккуратно увеличены (Lanczos), новых деталей это не добавляет.
Подписи к фото на сайте берутся из поля `photoSrc` в `data/heroes.js`.

## Что стоит сделать до защиты

- Для четырёх несвободных фото лучше получить письменное разрешение (музей, редакция) или найти оригинал в районном музее.
- Прежние фото команды (Хоружая, Осипова, Евфросиния, Докутович) заменены на снимки с известным источником. Оригиналы команды лежат в `nitki-pamyaci-photos-originals/`. Прежнее фото Докутович оказалось отретушированной (вероятно, нейросетью) версией снимка из книги Чечнёвой.
- Альтернатива для Хоружей лучшего качества, но без свободной лицензии: портрет в вышитой блузке из фондов Белорусского государственного музея истории Великой Отечественной войны: https://www.warmuseum.by/upload/medialibrary/78a/bm9p3z1mr9c62icqdvsuhlyhrg9cjgdk.jpg

Остальные файлы в этой папке (`gomel-palace`, `gomel-war-museum`, `krasny-bereg`, `mazyr-castle`, `ola`, `radiation-reserve`, `turau`, `vetka-museum`) — фото мест, их положил сюда кто-то другой при работе над картой (на 18.10.2026 ни один файл данных на них не ссылается). Скорее всего, им место в `assets/img/places/`; их источники здесь не описаны.
